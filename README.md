# KHUTABARI Portal

A simple and efficient portal designed for tenants to submit their electricity readings and view their monthly rent bills online.

## ✨ Features
- **Submit Reading:** Tenants can easily enter and send their monthly electricity meter readings.
- **View Bill:** Tenants can securely view their rent summary and bills by logging in with their **10 digit Registered Mobile Number**.
- **Responsive Design:** Optimized for a seamless experience on both mobile and desktop devices.

## 🛠️ Tech Stack & Backend
- **Frontend:** HTML, CSS, JavaScript
- **Backend & Database:** Powered by **Google Firebase** for secure, real-time data storage and authentication.
- **Admin Management:** All data is managed and monitored via the **KHUTABARI ADMIN APP**.
- **Hosting:** Deployed on **GitHub Pages**.

## 🚀 How to Use
1. Access the portal via the GitHub Pages link - https://adideb23.github.io/Khutabari
2. **To Submit Reading:** Enter your current electricity meter reading in the provided field and click submit.
3. **To View Bill:** Enter your registered mobile number to log in and access your personalized billing dashboard.

---
**Note:** This portal is strictly intended for the registered tenants of the KHUTABARI Portal only.
